## 🚀 你的第一週探索藍圖

在進入宇宙的前七天，建議跟隨本手冊的腳步循序漸進達成以下關鍵里程碑：

- **Day 1：搞定基礎配備與帳號**
  - 確認電腦硬體配置與 SSD 空間設定、選購合適新手包、完成角色外觀客製化。
- **Day 2：醒來與踏出第一步**
  - 熟悉全身肢體互動系統 (Inner Thought)、掌握 mobiGlas 手環介面、搭乘大眾運輸前往太空空港 (Spaceport)。
- **Day 3：首航與躍遷**
  - 呼叫航管 (ATC) 開啟機庫艙門、垂直起飛脫離星球大氣層、啟動量子引擎完成第一次量子跳躍 (QT)。
- **Day 4：宇宙生存法則**
  - 學會維持飢餓值與口渴值、認識 Tier 1-3 創傷急救與隨身醫療筆用法、避免觸犯 UEE 法律與被通緝。
- **Day 5：賺取第一桶金**
  - 體驗貨運電梯物流搬運、接取入門傭兵或賞金任務、嘗試手持牽引光束與船艦打撈採礦。
- **Day 6：熟練與裝備升級**
  - 利用 Erkul 規劃飛船配備升級（更快的量子引擎、更厚的護盾），熟悉常用快捷鍵。
- **Day 7：踏入深空與結伴同行**
  - 加入社群組織（如 SNRO），與艦隊夥伴一起駕駛大型多聯艦船體驗深空開拓。

## 🛠️ 本地開發與驗證 (Docs-as-Code)

本專案採用嚴格的 Docs-as-Code 架構，所有 Markdown 文件、YAML Frontmatter、內部超連結與 GitBook 語法區塊皆由自動化測試腳本把關。

你可以在本地透過 Docker 容器環境獨立執行驗證（無需在主機預先安裝 Node.js 環境）：

```bash
# 執行全專案結構、超連結、Frontmatter 與標題階層檢驗
docker run --rm -v "$(pwd)":/docs -w /docs node:lts-alpine node scripts/validate-docs.js
```

1. **回報問題**：若發現手冊內容有錯別字、資訊過期或連結失效，歡迎提出 [GitHub Issue](https://github.com/cosmo-chang-1701/star-citizen-beginner-guide/issues)。
