# 4.3：記得吃飯喝水！基礎的生存需求

為了提供極致的擬真沉浸感，《星際公民》導入了貼近真實人體的生存代謝系統。雖然不若硬核純生存遊戲般嚴苛，但若在長途遠征或荒野探險中完全忽視體能指標，依然會導致嚴重後果。

---

## 生理機能指標與脫水飢餓懲罰

在 HUD 抬頭顯示器的左下角，常駐有兩個關鍵的生存圓形量表：

- **水份儲備 (Hydration - 水滴圖標)**：隨時間持續衰退，若在高溫環境奔跑則衰退加劇。
- **熱量營養 (Nutrition - 漢堡圖標)**：衰減速度較水份稍慢，支撐肌肉基礎運作。

### 忽視補給之後果警告

當任一指標跌破 **20%** 危險警戒線時：
1. **耐力劇烈衰竭**：衝刺幾步便會陷入嚴重氣喘，武器瞄準大幅劇烈抖動。
2. **視覺暈眩與幻覺**：螢幕邊緣泛黑泛白，視線逐漸模糊。
3. **昏厥休克身亡**：若持續放任跌落至 0%，角色將直接因器官衰竭而倒地身亡，身上未備份的裝備將全數掉落原地。

### 物資取得管道

- **主城與空間站**：各大港口的便利商店（如 Casaba Outlet 旁的小舖、Whammers 漢堡店、Burrito 捲餅吧台）與自動販賣機。
- **戰術搜刮 (Looting)**：野外地堡、前哨站儲藏室與廢棄飛船殘骸的物資箱內，經常能翻找出口感極佳的高級水果與補給水瓶。

## 進食飲水標準操作程序 (SOP)

{% stepper %}
{% step %}
### 脫下全罩式太空頭盔

這是一切悲劇最常發生的源頭！頭盔面罩鎖定狀態下是無法進食的：
- 在安全氣密環境（船艙內部或主城室內）按下快捷鍵 **`左 Alt + H`** 卸除頭盔。
- 也可以按 `I` 開啟背包，將頭盔手動拖曳至口袋或地上。

> [!CAUTION]
> 絕對不要在缺乏大氣的月球表面或外太空直接脫下頭盔，否則將在 5 秒內因失壓窒息！
{% endstep %}

{% step %}
### 取出並手持飲品或食物

開啟背包，找到你想食用的飲品（如 Cruz 系列能量水）或食物（能量棒、漢堡），滑鼠右鍵點擊選擇 **「Carry」** 或 **「Equip」** 手持。
{% endstep %}

{% step %}
### 長按 F 鍵執行食用指令

低頭注視手中握持的物品，**按住 `F` 鍵**，在浮現的選單中點擊 **「Drink」** 或 **「Eat」**：
- 角色會做出精細的旋開瓶蓋並仰頭暢飲的物理動作。
- HUD 上的水滴或漢堡百分比將迅速回升至 100%。
{% endstep %}

{% step %}
### 務必重新戴回太空頭盔

進食完畢後，**再次按下 `左 Alt + H` 戴回頭盔**！
- 走出太空站或跨入減壓艙前，務必按 `F4` 切換第三人稱視角確認頭盔已牢固佩戴在頭部。
{% endstep %}
{% endstepper %}

## 極端氣候防護服與體溫管理

宇宙各星球的表層溫差動輒超過數百度，常規輕型飛行服無法抵禦極端氣候：

- **極寒防護服 (Novikov Suit)**：前往 microTech 暴風雪冰原或嚴寒洞穴時必穿，提供高達零下數十度的抗寒保暖層。
- **極熱重裝防護服 (Pembroke Suit)**：登陸 Aberdeen (阿伯丁) 等高溫煉獄星球時必備，具備大型背負式主動冷卻空調系統。
- **微氣候體溫警訊**：若穿著常規護甲進入極端環境，HUD 體溫指標會迅速失衡，幾分鐘內即會因中暑或失溫陷入昏迷。
