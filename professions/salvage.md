# 3.4：打撈：工業循環與製造體系的支柱

在目前的宇宙中，打撈 (Salvage) 已徹底擺脫「單純刮鐵皮」的初期刻板印象，昇華為**製造、後勤修復與科技逆向工程生態系**不可或缺的支柱產業。打撈者不僅清理戰場殘骸，更是維持船隊現場裝甲續航、提供稀有製造原料的工業先驅。

---

## 打撈職涯與聲望階梯

打撈業務由大型回收巨頭 **Adagio Holdings** 全權管理，合約聲望直接決定了你有資格獲准拆解的船艦殘骸噸位：

| 聲望等級 | 可承接目標規模 | 代表目標船型 |
| :--- | :--- | :--- |
| **中立 (Neutral)** | 輕型/偵察殘骸 | Aegis Gladius、Anvil Arrow、Drake Cutter |
| **初級承包商 (Jr. Contractor)** | 中型多功能艦 | RSI Zeus Mk II、Aegis Sabre、MISC Freelancer |
| **正式承包商 (Contractor)** | 重型砲艇與護衛艦 | RSI Constellation、Aegis Retaliator、Drake Corsair |
| **資深/精銳承包商 (Senior/Elite)** | 次主力艦與巨型工業船 | Aegis Hammerhead、MISC Starfarer、Drake Caterpillar |

> [!TIP]
> **關鍵藍圖收益**：千萬不要只做常規花錢買點位的殘骸任務！請務必完成初期的**「交付合約 (Turn-in Contracts)」**，這是取得高階**打撈雷射頭模組藍圖 (Salvage Module Blueprints)** 的唯一穩定管道。

---

## 打撈產出物：RMC 與 CMAT 的核心分工

打撈作業產出兩種關鍵性工業材料，在**製造系統 (Crafting)** 中各自扮演無可取代的角色：

| 材料名稱 | 英文全稱 | 採集方式 | 核心用途與經濟價值 |
| :--- | :--- | :--- | :--- |
| **RMC** | Recycled Material Composite | 船體表層刮除 (Hull Scraping) | 裝甲快速修補、生產船殼保護板與外裝甲模組（戰鬥船隊極度渴求的急救消耗品）。 |
| **CMAT** | Construction Materials | 內部骨架粉碎 (Fracturing & Disintegration) | 需經精煉處理，是製造 Size 2 以上發電機、護盾產生器與量子跳躍引擎骨幹的必備材料。 |

## 完整打撈與逆向工程循環

{% stepper %}
{% step %}
### 鎖定殘骸與抵達作業區

在 mobiGlas 的 Contract Manager 接受 Adagio Holdings 的打撈合約，躍遷至指定深空或廢棄衛星座標。優先鎖定高聲望、高完整度的廢棄軍用船隻。
{% endstep %}

{% step %}
### 登船搜刮內部核心組件 (Component Stripping)

在破壞艦體結構之前，先穿戴 EVA 太空服進入殘骸駕駛艙或工程艙，按下 **`Right Alt + K`** 解鎖艦船介面：
- 使用牽引光束將完好的高級軍規級冷卻器、武器與量子引擎整顆拆下裝入自船貨艙。
- 高品質廢棄組件可帶回研究終端進行「科技逆向拆解」，有機率解鎖稀有改良藍圖！
{% endstep %}

{% step %}
### 表層刮除 (Hull Scraping) 採集 RMC

坐回打撈船操縱席，按下 **`M`** 切換至打撈模式：
- 瞄準艦體平滑表面啟動刮除光束，剝離裝甲塗層並自動壓縮為標準 1 SCU 規格的 RMC 箱。
- 在團隊協同作戰中，RMC 箱可即時交由隊友的多功能工具「修復配件 (Cambio-SRT)」，在戰場第一線對重損戰機進行裝甲熱修補！
{% endstep %}

{% step %}
### 結構破裂與骨架解體 (Fracturing & Disintegration)

當船殼刮除淨空後，啟動高能量破碎力場將整艘骨架炸裂為碎塊，隨後開啟吸引力場進行分子級粉碎解體：
- 數十秒內將整艘主力艦殘骸消化為純粹的 **CMAT 建築材料**。
- 將原材運回精煉廠處理後，即可投入工坊組裝個人專屬的客製化頂級飛船核心組件。
{% endstep %}
{% endstepper %}
