# 3.3：採礦：工業與製造體系的基石

在目前的宇宙中，採礦已不再僅僅是獲取 UEC 貨幣的手段，它已躍升為**製造系統 (Crafting)** 的核心基石。隨著**資源品質分級 (Quality Bands)** 機制的深度整合，礦工的定位已由單純的原礦採掘者，昇華為供應高端稀有金屬、驅動宇宙精密工業運轉的關鍵專業職人。

## 核心機制：品質等級與製造鏈

每一塊礦石均擁有其固有的**品質等級 (Band 1-8)**，這直接決定了下游製造鏈的附加價值：

1. **品質分級 (Quality Bands)**：
   - **Band 1-3**：基礎工業材料，適用於大規模結構建設或作為組件製造的填充金屬。
   - **Band 4-6**：中階工業材料，用於生產全星系統一規格的標準民用飛船組件。
   - **Band 7-8**：頂級特種合金，是製造軍規級 (Military) 或競賽級 (Competition) **藍圖 (Blueprints)** 頂規組件的必備原材料。
2. **藍圖協同製造**：採礦獲得的高等級稀有礦石是長久保留遊戲進度的核心。透過高階聲望取得的傳奇藍圖，唯有搭配 Band 7 以上的極品礦物，方能淬鍊出極限性能組件。

## 採礦標準作業程序 (SOP)

{% stepper %}
{% step %}
### 探勘掃描與品質光譜分析

按下 `V` 鍵啟動長程掃描模式發出雷達脈衝。接近岩體後，HUD 會顯示岩體的成分構成與 **Quality Band** 等級。身為追求高報酬的專業礦工，應優先鎖定高純度 Quantanium 或 Band 7 以上的高品質礦脈。
{% endstep %}

{% step %}
### 破裂程序：熱量與能量平衡

對準岩體後按下 **`M`** 鍵進入採礦作業模式。滑動滑鼠滾輪調控雷射輸出功率，將岩體熱量指標嚴格維持在**綠色最佳區間**。
- **電阻控制**：若遭遇高電阻或極不穩定的岩體，可加裝 **Sabir** 或 **Boremax** 破裂模組，有效壓制爆裂風險。
- **防止超載**：切勿讓能量條衝入紅色超載區，否則岩石將劇烈爆炸並重創飛船。
{% endstep %}

{% step %}
### 碎片萃取與易爆品轉移

岩體順利碎裂為小型塊狀後，切換至萃取光束將高價值原礦吸入飛船礦箱：
- **易爆量子礦 (Quantanium) 警報**：若採集到 Quantanium 原礦，HUD 會立即啟動**不穩定倒數計時器**！你必須在計時歸零前全速航向最近的精煉廠空間站，將飛船停妥入庫，否則礦箱將發生毀滅性殉爆。
{% endstep %}

{% step %}
### 精煉加工與商業變現

將滿載的礦船停靠於設有精煉廠的空間站（如 HUR-L1、CRU-L1 等）：
- **精煉工藝抉擇**：在精煉終端機選取精煉方法（如 Dinyx Solventation 或 Cormack Method），權衡精煉**良率**與**等待時間**。
- **產出分流**：精煉完成的高純度金屬錠，既可裝入貨船運往各大主城貿易中心 (TDD) 獲取百萬 UEC，亦可存入個人基地倉庫作為後續自製高級組件的戰略物資儲備。
{% endstep %}
{% endstepper %}

## Drake Golem (魔像) 實戰小撇步

作為新一代採礦入門艦船，魔像在實戰中具備顯著的機動優勢：

1. **碎石帶幽靈**：其靈巧的船體能輕鬆在 **Yela 光環**或 **Aaron Halo (阿隆光環)** 的高密度小行星帶內靈活穿梭。
2. **機械臂視角適應**：由於採礦雷射固定於右側機械臂，校準礦石中心點時建議微調機頭俯仰角度 (Pitch)。
3. **深耕 Shubin 聲望**：優先承接舒賓礦業的初期合約，快速累積信譽以換取 **Helix** 採礦頭藍圖，賦予魔像越級開採巨型岩石的能力。
