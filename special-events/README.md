# 第五章：深入進階 - 特殊活動指南

公民，當你熟悉了基本的飛行、貿易與戰鬥後，是時候將目光投向更具挑戰性的史詩戰役了！

宇宙並非一成不變，開發商 CIG 會隨著遊戲版本演進，不定期舉辦各式各樣的大型「動態特殊活動」。這些活動不僅能讓你體驗到全伺服器玩家高度協作的震撼場面，更是獲取官方帳號永久綁定 (Wipe-Immune) 稀有裝備的絕佳機會。

---

## 🎯 本章核心目標

- **掌握動態戰役：** 熟悉多階段任務結構（偵察、破網、防空、登陸與 Boss 戰）。
- **永久帳號資產：** 了解最新「帳號直發防重置 (Wipe-Immune)」獎勵機制與聲望進度。
- **跨版本戰術沉澱：** 學習歷代重大活動的配裝原則與團隊作戰策略。
