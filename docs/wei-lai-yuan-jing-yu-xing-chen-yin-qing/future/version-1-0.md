# 6.1：「1.0 版本」代表什麼？這是一個全新的開始！

「1.0 版本」是《星際公民》自立項以來的正式商業發布版。這不僅僅是一個版本數字的跳躍，它宣告著這款龐大的太空模擬器將正式告別長達十餘年的「Alpha 早期技術驗證」階段，蛻變為一款架構穩定、經濟自洽、且能長久陪伴玩家的 3A 級商業線上鉅作。

---

## 告別 Alpha 測試：商業發布之核心承諾

### 終結刪檔循環：永久進度保存

隨著官方將 2026 年定為「可玩性之年」(Year of Playability)，《星際公民 1.0》的到來已成為開發團隊的首要核心目標：

- **告別資料清空 (No More Wipes)**：在目前的測試階段，重大版本更新仍可能伴隨資料庫重置；然而隨「藍圖保存機制」的實裝，長效進度體系已悄然成型。從 1.0 版本正式發售起，你在宇宙中開拓積累的所有飛船、客製組件、聲望資產與貨幣財富將永久存續！
- **時間與精力獲得保障**：作為一款真實社會結構的 MMO，永久進度是吸引硬核玩家與休閒玩家全情投入的基石。

### 完整機制串聯與高水準打磨

1.0 版本絕非粗製濫造的及格線，而是成熟商業大作的起跑點：
- 工程維修、物理貨運、星門跳躍、多星系經濟與深度製造藍圖系統將全面閉環串聯。
- 官方公開路線圖已正式設立專屬的「1.0 核心專欄」，公開每項發售必備特性的研發百分比。

## 迎接主流玩家：從技術實驗到 3A 級線上鉅作

過去，「Alpha」這個標籤往往伴隨著效能不穩與繁雜 Bug，讓許多潛在公民望而卻步。卸除這個標籤，代表著 CIG 向全球玩家宣告：這個宇宙已經準備妥當，歡迎所有人登艦啟航！

對於剛進入宇宙的新公民而言，你正身處於歷史性轉折的黃金黎明——見證從測試原型走向完整宇宙的偉大轉身。
