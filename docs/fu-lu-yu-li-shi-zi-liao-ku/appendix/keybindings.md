# 附錄 A：快還要更快！新手必備快捷鍵小抄 (官方預設版)

《星際公民》的鍵位系統繁複且細膩。隨著大師模式 (Master Modes)、EVA 物理噴氣推進、工程資源網格 (Resource Network) 與寄生子機對接等核心架構全面就緒，掌握高頻核心快捷鍵能大幅提升生存率與操作流暢度。

本篇整理了官方預設 (Default) 最核心的高頻快捷鍵，依場景分為 5 大模組化標籤頁速查，並提供實用進階自訂熱鍵與避坑操作建議。

## 實用提醒與避坑指南

### 1. 外門自訂快捷鍵：防跳幫與緊急抽真空滅火

在當前版本中，**「開啟/關閉全船所有外門 (Open/Close All Doors)」預設並未綁定快捷鍵**。在多元宇宙冒險中，這是極具威脅的防護漏洞：

- **防止陌生玩家跳幫偷渡 (Anti-Boarding)**：在空間站停機坪、公共採礦哨站或裝卸貨物時，舷梯與外門敞開極易被潛伏的海盜玩家潛行溜入座艙偷船甚至行刺。
- **火災抽真空滅火 (Emergency Vacuum Venting)**：隨著工程資源網格系統實裝，組件過熱受損容易引發火災。若火勢迅速蔓延，手持滅火器撲救費時費力；此時一鍵開啟全艦外門讓艙內空氣抽真空，是最速撲滅明火的有效自救手段。

> [!TIP]
> 強烈建議前往遊戲設定 `Options > Keybindings > Vehicles - Cockpit`，找到 **Open/Close All Doors**，自行綁定一組順手且不易誤觸的快捷鍵（例如 `右 Alt + [` 或小鍵盤 `Numpad /`）。

### 2. 牽引光束貨物裝卸：防砸船與防物體穿模事故

使用多功能工具牽引光束或艦載牽引砲塔搬運箱體時，請務必遵循以下物理安全準則：

- **嚴禁猛烈甩動貨物**：物體被牽引光束吸附時具有真實物理質量。快速揮動滑鼠會賦予箱體巨大動量，若高速撞擊艦船外殼、組件配電箱或座艙玻璃，將直接造成艦體嚴重受損甚至誘發殉爆。
- **善用距離微調與旋轉對齊**：善用 `R + 滑鼠滾輪` 調節安全距離，並按住 `R + 滑鼠移動` 旋轉箱體，確保貨物平穩貼合底座貨物網格 (Cargo Grid) 完成磁吸固定。
- **EVA 零重力反作用力注意**：在 EVA 艙外真空環境中牽引超重物體 (如 32 SCU 大型貨櫃) 時，自身會產生明顯的反作用力位移。操作時務必配合噴氣背包反推或開啟磁吸靴 (`B`) 吸附艦體外殼穩定身軀。

> [!WARNING]
> 搬運易燃爆品、不穩定量子礦石 (Quantanium) 或高價值易碎品時，務必在牽引前先將飛船主引擎關閉 (`I`) 並減慢操作手速，避免物理引擎碰撞穿模引發致命意外。
