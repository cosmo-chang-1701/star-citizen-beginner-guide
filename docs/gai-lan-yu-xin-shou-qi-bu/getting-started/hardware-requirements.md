# 1.1：我的電腦跑得動嗎？硬體需求溫馨提醒

在所有步驟開始之前，最現實的問題是：你的電腦能應付這個被稱為「硬體殺手」的遊戲嗎？老實說，《星際公民》對硬體的要求非常高。官方網站上的「最低需求」僅僅代表「能打開遊戲」，離「順暢遊玩」還有很長一段距離。

以下是我們根據大量社群玩家的實測經驗，為你整理的 2026 年新手入門標準。

---

## 核心硬體入門標準

### 固態硬碟 SSD（強制要求）

- **要求門檻：** **官方強制性要求，傳統硬碟 (HDD) 已不被支援。**
- **技術原因：** 《星際公民》採用全實體資料串流技術 (Object Container Streaming)，遊戲過程中會即時讀取海量模型與高解析材質。若安裝在傳統機械硬碟 (HDD) 上，會引發毀滅性的卡頓、貼圖消失（如掉入地底太空深淵）甚至直接崩潰。
- **配置建議：** 必須安裝於 SSD 上，遊戲本體加更新需預留至少 150GB 可用空間。強烈建議選用 **NVMe M.2 SSD**，其高速讀取通道對於 2026 年版本（如 Alpha 4.x）至關重要。

### 記憶體 RAM（32GB 流暢基準）

- **要求門檻：** **最低 16GB，強烈建議 32GB 或更高。**
- **技術原因：** 雖然官方最低標準標示 16GB，但在各大行星主城（如羅威爾 Lorville 或 18 區 Area18）中，記憶體佔用量經常突破 20GB。16GB 系統將被迫頻繁調用虛擬分頁檔案，導致嚴重的微卡頓 (Stuttering)。
- **配置建議：** **32GB DDR4/DDR5** 是目前公認的標準配備。若有背景多工或實況直播需求，直上 64GB 亦是非常合理的投資。

### 中央處理器 CPU（L3 快取的勝利）

- **指令集支援：** CPU 必須支援 **AVX、AVX2 與 FMA3** 指令集（Intel Haswell / AMD Excavator 以後架構）。
- **處理器特性：** 《星際公民》極度依賴 CPU 計算複雜的物理碰撞與實體網路同步。目前 **AMD Ryzen X3D 系列**（如 7800X3D、9800X3D）憑藉巨大的 3D V-Cache，在遊戲中展現出壓倒性的最低幀率 (1% Low FPS) 優勢。
- **GPU 卸載技巧：**
  > [!IMPORTANT]
  > 在遊戲設定中，將「品質」(Quality) 選項設定為「高」(High) 或「非常高」(Very High)。這會促使渲染引擎將更多計算任務從 CPU 卸載到 GPU，在多數非頂級配置上反而能提升幀率。

### 顯示卡 GPU 與 Vulkan API

- **驅動與 API：** 顯示卡必須支援 **Vulkan 1.2** 與 DirectX 12。
- **顯示卡建議：** 建議配備至少 **12GB VRAM** 的顯示卡以應付複雜場景材質。若在 1440p 或 4K 解析度下游玩，RTX 4070、RTX 50 系列或 AMD RX 7900 GRE 是理想選擇。

### 記憶體超頻 XMP / EXPO

- **為什麼重要？** 進入主機板 BIOS 確認已啟用 XMP (Intel) 或 EXPO (AMD)，確保你的記憶體運行在標稱頻率（如 DDR5-6000MHz）。未開啟此功能會導致記憶體以預設慢速運行，造成顯著的效能浪費。

## 系統優化與軟體調校

### 遊戲內影像最佳化設定 (Options -> Graphics)

- **品質 (Quality)：** **High** 或 **Very High**（善用 GPU 渲染分擔）。
- **星球體積雲 (Planet Volumetric Clouds)：** 效能殺手！建議設為 **Medium** 或直接關閉 **Off**。
- **畫面升級技術 (Upscaling)：** 提升幀率的核心法寶。NVIDIA 顯示卡開啟 `DLSS 3.5+`，AMD/Intel 開啟 `FSR 3+` 或 `XeSS`，建議模式選擇 **Quality**。
- **繪圖 API (Graphics API)：** 選擇 **Vulkan**，能大幅釋放多核心 CPU 性能。

### 驅動程式與系統層級調優

- **著色器快取 (Shader Cache Size)：** NVIDIA 使用者請在控制面板中將著色器快取設為 **10 GB** 或 **無限制**，可大幅消除初次載入場景時的著色器編譯卡頓。
- **虛擬記憶體分頁檔 (Pagefile)：** 若系統僅有 16GB 或 32GB RAM，請在 SSD 上手動設定至少 16GB~32GB 的固定分頁檔案，防止記憶體溢出 (OOM) 導致遊戲閃退。
- **停用全螢幕最佳化：** 在 `StarCitizen.exe` 檔案屬性中勾選「停用全螢幕最佳化」，能降低部分系統的輸入延遲。
