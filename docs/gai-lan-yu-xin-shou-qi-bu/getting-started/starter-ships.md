# 1.3：我的第一艘船該怎麼選？一個影響深遠的決定

你的第一艘飛船不僅是你在宇宙中的第一個「家」，更是你在星際中賺取第一桶金的核心生產力工具。隨著遊戲機制的深化，入門船的選擇已從簡單的「戰鬥或送貨」演變為「初生職業路徑的選擇」。

以下是我們為新進公民篩選出的三種最佳入門啟航方案。

---

## 三大主流新手啟航艦評比

### 1. 經濟首選：RSI Aurora Mk II (極光 Mk II)

這是繼承了經典極光系列精神的新一代入門機型，也是目前預算最友善、最穩健的起跑線。

| 評估維度 | 詳細說明 |
| :--- | :--- |
| **官方購買** | [RSI Aurora Mk II 新手遊戲包](https://robertsspaceindustries.com/en/pledge/Packages/Citizen-Starter-Pack) |
| **艦船定位** | **多功能通用輕型入門機** |
| **核心優勢** | **超高性價比、模組化空間**。Mk II 優化了內部空間結構，保留了可供隨時離線休息存檔的**生活床位**，並具備可掛載小型貨物的外部貨格。 |
| **適合玩法** | 基礎快遞貨運、初階維修調查、輕型巡邏任務。 |
| **老鳥評語** | 如果你想用最低的預算踏入宇宙，並享有隨時在星空中離線躺平的權利，極光 Mk II 是性價比無可挑剔的起點。 |

---

### 2. 全能王者：Aegis Avenger Titan (復仇者 泰坦)

儘管遊戲版本持續演進，泰坦在當前宇宙環境中依然穩坐「新手村霸主」的寶座。

| 評估維度 | 詳細說明 |
| :--- | :--- |
| **官方購買** | [Aegis Avenger Titan 決鬥者新手包](https://robertsspaceindustries.com/en/pledge/Packages/Duelist-Starter-Pack) |
| **艦船定位** | **戰鬥 / 運輸雙修萬金油** |
| **核心優勢** | **全能性無可替代**。機鼻搭載 4 號武器掛點，具備強大的中程火力；擁有 8 SCU 的內部實體貨艙，尾部**平整坡道門**讓你在運送物資或地堡突擊搬運裝備時極其便捷。 |
| **適合玩法** | 中級賞金空戰、武裝護航、地堡戰術突擊、多階段複雜合約。 |
| **老鳥評語** | 若你的預算允許額外投入約 20 美元，泰坦能讓你直接跳過新手前期的貧弱過渡期，具備參與宇宙中絕大多數高收益活動的能力。 |

---

### 3. 工業起點：Drake Golem (德雷克 魔像)

專為「立志成為專業工業人」的新進公民所設計的全新特色機型。

| 評估維度 | 詳細說明 |
| :--- | :--- |
| **官方購買** | [Drake Golem 工業新手包](https://robertsspaceindustries.com/en/pledge/Packages/Miner-Starter-Pack) |
| **艦船定位** | **工業採礦與物資處理專用機** |
| **核心優勢** | **自帶專業工具**。整合了輕型採礦雷射頭與物資粉碎裝置，讓新玩家從第一天起就能直接參與宇宙中最穩健的經濟循環：採礦與精煉。 |
| **適合玩法** | 小行星帶勘探、地表露天採礦、精煉廠加工貿易。 |
| **老鳥評語** | 厭倦打打殺殺的玩家的最佳福音！魔像的外型雖然粗獷笨重，卻是新手致富速度最快、最不依賴戰鬥技巧的工業金鑰匙。 |

---

## 決策指南：你該選哪一艘？

- **預算有限，想全方位體驗宇宙生活：** 毫不猶豫選擇 **Aurora Mk II**。
- **渴望強悍火力、重視機庫空間與實用性：** 推薦直上 **Avenger Titan**。
- **志在工業致富、偏好穩定採礦：** 推薦選購 **Drake Golem**。

> [!TIP]
> **官方飛船升級機制 (Cross-Chassis Upgrade / CCU)：**
> 所有的入門船未來都可以隨時在官網透過「Ship Upgrades」功能**僅補差價**升級成更高級的船艦。例如先以 Aurora Mk II 起步，日後若熱愛採礦，只需補齊差額即可無痛轉換為 Golem，原有的遊戲包權限與保險均會完整繼承！
