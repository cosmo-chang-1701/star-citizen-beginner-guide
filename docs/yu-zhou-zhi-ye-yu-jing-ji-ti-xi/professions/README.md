# 第三章：開始賺錢吧！找到你喜歡的宇宙職業

公民，當你掌握了飛行的真諦，是時候在宇宙中開啟你的職業生涯、累積人生第一筆 aUEC 財富了！

《星際公民》擁有極度擬真且職能分明的社會經濟系統。無論你喜歡穩定低風險的貨運物流、追求心跳加速的賞金追獵，還是渴望建立屬於自己的工業帝國，這裡都有屬於你的一席之地。

---

## 🎯 本章核心目標

- **探索職業類型：** 全面了解五大核心職業的玩法特色、門檻與報酬結構。
- **掌握實體裝卸：** 適應現代貨物電梯與手動牽引光束裝卸機制。
- **解鎖工業製造：** 了解採礦精煉、殘骸結構拆解與零件藍圖獲取途徑。
- **後勤支援體系：** 體驗深空加油與團隊艦隊護航的商業價值。
