# 1.2：如何成為公民？帳號與遊戲包的購買指南

硬體確認沒問題後，我們就可以正式註冊帳號，領取你的公民證了！這個過程有幾個關鍵細節，一旦忽略將錯失大量免費初始福利。

---

## 公民入坑四部曲

{% stepper %}
{% step %}
### 創建你的 RSI 帳號

前往《星際公民》官方網站的 [帳號註冊頁面 (Enlist)](https://robertsspaceindustries.com/enlist)，填寫你的帳號代號 (Callsign)、電子郵件與密碼。

{% hint style="warning" %}
帳號建立完成後，強烈建議立即前往帳號設定頁面啟用 **雙重身份驗證 (Two-Factor Authentication / 2FA)**，保護你的飛船與數位資產安全。
{% endhint %}

{% endstep %}

{% step %}
### 填寫社群推薦碼 (Referral Code)

這一步是所有新玩家最容易遺漏、也最令人懊悔的環節！在註冊表單底部的 **Referral Code** 欄位填寫推薦碼：

- **額外獲贈 5,000 UEC：** 填寫推薦碼後，你的帳號會永久獲贈 5,000 UEC（或活動期間高達 50,000 UEC）的初始遊戲貨幣。
- **特賣活動額外好禮：** 在官方大型特賣期間（如 5 月的 Invictus 艦隊週或 11 月的 IAE 航太展），官方通常會加碼贈送絕版載具、地面裝甲或武器套裝。
- **推薦碼推薦：** 歡迎使用作者的社群推薦碼：`STAR-3SGF-2Y3F`，也可以向你的公會戰友索取。
{% endstep %}

{% step %}
### 認清「遊戲包」與「獨立船艦」

進入官網商城 (Pledge Store) 結帳時，請務必辨認商品類型：

| 類型 | 商品名稱特徵 | 包含內容 |
| :--- | :--- | :--- |
| **遊戲包 (Game Package)** | 標註 **Star Citizen Digital Download** | **擁有遊戲進入權限** + 獲得該艘飛船（新手必備） |
| **獨立飛船 (Standalone Ship)** | 僅標註飛船名稱與保險期 | 僅包含船隻本體，**不含遊戲進入權限**（切勿買錯！） |

{% hint style="warning" %}
如果只購買了「獨立飛船」而沒有任何「遊戲包」，你將無法登入持久宇宙 (Persistent Universe)！
{% endhint %}

{% hint style="info" %}
**重要機制：Game Access 遊戲存取保護系統 (2026/11/01 生效)**
CIG 官方自 2026 年底全面實施 **Game Access** 保護機制。購買新手遊戲包後，系統會將該遊戲包指定於官方機庫的「My Hangar -> Game Access」，為帳號提供永久遊玩存取權限。受保護的遊戲包具有**防誤融 (Non-meltable)** 與**防誤贈 (Non-giftable)** 特性，徹底杜絕玩家因手誤融解遊戲包而無法登入伺服器的問題。
{% endhint %}

{% endstep %}

{% step %}
### 購買官方首航包與下載啟動器

為了降低新手入坑門檻，CIG 官方商城已全面整合並推出單一標準遊戲包：**[Star Citizen First Flight Pack (星際公民首航包)](https://robertsspaceindustries.com/en/pledge/Packages/Star-Citizen-First-Flight-Pack)**。

所有新進公民只需購買此單一遊戲包即可獲得完整遊玩權限，內容包含：

- **永久主力起航艦：羅伯茲太空工業 (RSI) 極光 Mk II (Aurora Mk II)**（具備基礎貨物外掛格、護盾與可供隨時離線休息存檔的生活床位）。
- **30 天多職業體驗艦隊 (30-Day Loaners)：** 官方特別加贈 30 天專用船艦租借權限，無須額外付費即可體驗三大主流職業：
  - 採礦體驗：**德雷克星際 魔像 (Drake Golem)**
  - 打撈體驗：**武藏工業與星航公司 財運 (MISC Fortune)**
  - 貨運體驗：**十字軍工業 無畏 (Crusader Intrepid)**
- **靈活升級機制 (CCU)：** 若日後想更換為聖盾動力 復仇者 泰坦 (Aegis Avenger Titan) 等熱門進階船艦，只需透過官網的「飛船升級 (Ship Upgrades / CCU)」功能補齊差價即可，或直接在遊戲內使用 aUEC 購買！

付款完成後，請下載最新的 **RSI Launcher 2.0** 官方啟動器，登入帳號即可開始高速下載遊戲本體。
{% endstep %}
