# 2.4：握緊駕駛桿！你的第一次飛行與量子跳躍

站在宏偉的機庫中央，凝視著屬於你的第一艘星際飛船，內心的激動難以言表。深吸一口氣，讓我們依序完成飛船冷啟動、塔台通聯、垂直起飛與第一次震撼的量子跳躍！

***

## 飛行起降與大師模式 (Master Modes) 指南

{% stepper %}
{% step %}
### 登船與座艙系統冷啟動

* **進入飛船**：繞行飛船找到入口（常見為尾部貨艙坡道、側舷艙門或機腹折疊梯），按住 `F` 鍵點擊「Open Exterior」或「Enter Ship」。
* **入座駕駛席**：走向艦橋駕駛座，按住 `F` 點擊「Enter Pilot Seat」。
* **啟動艦載系統**：
  1. 按下 **`U`** 鍵啟動飛船總電源（Power On）。
  2. 按下 **`I`** 鍵點火啟動推進引擎（Engines On），座艙 HUD 與抬頭儀表板將全數點亮！
{% endstep %}

{% step %}
### 聯繫航管 (ATC) 取得起飛許可

機庫頂部或側面的防爆艙門預設處於閉鎖狀態，起飛前必須主動聯繫空中交通管制：

* **快速呼叫管制台**：按下快捷鍵 **`左 Alt + N`**（或開啟 mobiGlas 的 Friends 通訊頁籤呼叫該港 ATC）。
* **確認放行許可**：當耳邊傳來航管通訊廣播「You are clear to launch」，且上方的機庫巨型艙門緩緩敞開時，即代表已獲准離港。
* **垂直升空**：按住 **`空白鍵 (Space)`** 垂直拉升脫離地面。完全脫離機庫後，按下 **`N`** 鍵收回起落架。
{% endstep %}

{% step %}
### 大師模式 (Master Modes) 與量子跳躍

目前的飛行架構全面導入 **大師模式 (Master Modes)**，飛船分為兩種根本狀態：

* **SCM 戰鬥模式 (Speed Combat Maneuvers)**：限制在較低極速（約 200\~300 m/s），但護盾全開、機動性能最佳、武器系統可全功率開火。
* **NAV 導航模式 (Navigation Mode)**：按下 **`B`** 鍵切換至 NAV 模式。此時可加速至千米超音速極速，並解鎖量子躍遷能力（注意：護盾會暫時離線！）。

#### 執行首次量子跳躍步驟：

1. 按下 **`F2`** 開啟全息星圖 (Skyline)，雙擊目標地點（例如該星球上方的軌道空間站），點擊右上角 **「Set Route」** 設定航線。
2. 關閉星圖回到駕駛艙，按下 **`B`** 切換至 **NAV - QT (量子模式)**。
3. 將準星對準虛空中浮現的航線導航菱形標記。
4. **長按 `B` 鍵** 啟動量子引擎預熱（Spooling）與星標校準（Calibration），直到兩者進度均達到 100%。
5. **按住 `滑鼠左鍵`** 啟動量子跳躍，伴隨著超空間折疊的音爆，飛船將以數倍光速疾馳而去！
{% endstep %}

{% step %}
### 進場減速與空間站降落停靠

當量子跳躍結束、安全抵達目標空間站外圍後：

1. 按下 **`B`** 切換回 **SCM** 模式，恢復船體護盾並降低極速。
2. 飛行靠近空間站（距離約 5,000 公尺以內），再次按下 **`左 Alt + N`** 向該站 ATC 申請停靠許可。
3. 視線尋找 HUD 上出現的倒三角停機坪或機庫導引標記。
4. 接近泊位上方時按下 **`N`** 鍵放下起落架，使用 **`左 Ctrl`** 緩慢垂直下降接觸地面。
5. 成功著陸後，按下 **`I`** 關閉推進器引擎（避免飛船被暴風吹走），按住 **`Y`** 鍵離開駕駛座椅。
{% endstep %}
