# 2.3：告別你的小窩，如何從城市前往太空站

熟悉了徒步走動與物品管理後，現在是時候離開溫暖的公寓宿舍，搭乘大眾交通工具前往這座城市的太空港，召喚屬於你的第一艘星際飛船了。

***

## 城市通勤與取船四步驟

{% stepper %}
{% step %}
### 跟隨環境指標離開居住區

離開你的專屬公寓房間後，請放慢腳步觀察四周牆面與懸掛指示牌。遊戲世界採用了高度擬真的環境導引：

* **尋找交通指標**：尋找標有 **「Metro Loop」**、**「Transit」** 或 **「Spaceport」** 的標示。
* **搭乘生活區電梯**：各主城宿舍均設有直通底層大廳的大型電梯，按住 `F` 點擊「Ground Floor」或「Lobby」。
{% endstep %}

{% step %}
### 搭乘城市地鐵列車 (Metro / Transit)

各主城的規模極其龐大，居住區與太空港之間必須搭乘無人駕駛電車或高架地鐵通勤：

* **辨識月台方向**：在列車站月台上方會有電子看板標示終點站（例如前往 **Spaceport** 的月台）。
* **列車進出站**：電車通常每隔 1~~2 分鐘一班。車門開啟後步入車廂，車程約需 1~~3 分鐘。
* **抵達提醒**：當車載廣播與車門螢幕顯示「Spaceport」或「Terminal」時即可下車。
{% endstep %}

{% step %}
### 使用 ASOP 艦船交付終端機呼叫飛船

抵達太空港主大廳後，環顧四周尋找排列整齊的立式觸控螢幕——這就是 **ASOP (Automated Ship and Vehicle Delivery Terminal)**：

1. 走近終端機，長按 `F` 鍵並點擊螢幕開啟介面。
2. 畫面左側會列出你帳號下擁有的所有飛船與車輛列表。
3. 找到你的新手船，點擊右側的 **「Retrieve」**（或初次調度時點擊 **「Deliver」**）。
4. 終端機螢幕將顯示提示：「Ship Retrieved to Hangar XX」（例如分配在 Hangar 04 機庫）。
{% endstep %}

{% step %}
### 搭乘機庫專用電梯抵達機位

記住終端機分配給你的機庫編號：

* **尋找機庫電梯**：在 ASOP 終端機兩側通常就是通往各大機庫的電梯間（Hangars Elevator）。
* **選取目標機庫**：進入電梯後按住 `F` 鍵，在樓層面板中選取剛剛被分配的機庫編號（例如「Hangar 04」）。
* **踏入私人機庫**：走出電梯，眼前龐大而震撼的機庫中央，正靜靜停放著你的第一艘星艦！
{% endstep %}
{% endstepper %}
