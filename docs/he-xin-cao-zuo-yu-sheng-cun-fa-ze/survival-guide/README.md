# 第四章：想活得久一點？你必須知道的宇宙生存法則

在《星際公民》充滿驚喜的浩瀚宇宙中，除了欣賞壯麗的星雲與日落，殘酷的現實危險無處不在：突如其來的海盜襲擊、操作失誤造成的缺氧窒息、或者在低溫星球上體溫失衡。

活下去，是享受一切樂趣的前提。本章節將為你拆解宇宙中最關鍵的三大安全機制：醫療保險、執法系統與極端環境生理管理。

---

## 🎯 本章核心目標

- **醫療與防丟失：** 正確認識 3 級創傷系統、隨身醫療筆施打與空間站重生印記設定。
- **合法與執法底線：** 清楚了解犯罪評級 (CrimeStat) 的產生原因、繳費清單與克萊雪監獄服刑減刑技巧。
- **生理與環境求生：** 養成進食飲水習慣，並學會針對極端高低溫星球挑選對應防護服。
