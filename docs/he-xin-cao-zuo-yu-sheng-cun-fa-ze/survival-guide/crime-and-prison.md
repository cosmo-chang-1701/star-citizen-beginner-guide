# 4.2：當個好人還是壞蛋？了解一下犯罪系統

《星際公民》的文明世界並非法外樂園。在受地球帝國 (UEE) 司法管轄或企業治安監控的合法空域內，任何逾矩行為都會被星系通訊陣列完整記錄，並轉化為你的個人「犯罪等級」(CrimeStat)。

---

## 犯罪等級 (CrimeStat) 機制與代價

### 什麼是 CrimeStat？

CrimeStat (簡稱 CS) 是一套介於 1 到 5 級的動態通緝評估指標：

- **輕微違規 (CS1 ~ CS2)**：超時占用停機坪、低速擦撞他船、被巡警臨檢時查獲低階未申報貨物等。屬於民事違章，可繳交罰款解決。
- **重大罪行 (CS3 ~ CS5)**：未經授權入侵軍事管制區、蓄意擊毀無辜艦船、殺害安保人員或大量走私高危違禁品。屬於一級重罪，會觸發武裝追捕與逮捕入獄。

### 成為通緝犯的代價

一旦抬頭顯示器 (HUD) 右上角出現代表犯罪等級的紅色骷髏標記：

1. **港口防禦火網主動開火**：主城與合法空間站防空砲塔將直接鎖定你並發射致命飛彈。
2. **合法服務全面中斷**：無法使用 ASOP 終端叫船，加油、維修與補彈服務全數停權。
3. **引來賞金獵人獵殺**：你的座標與賞金將自動發布至全星系獵人的 mobiGlas 懸賞單上。
4. **逮捕強制遣返**：一旦被安保艦隊擊沉或失去行動能力被捕，將直接甦醒於深層地下的 **克萊雪自動化改造監獄 (Klescher Rehabilitation Facility)**。

## 洗清罪名與消除 CrimeStat 的三種途徑

{% tabs %}
{% tab title="途徑一：繳納行政罰款 (適用 CS1~CS2)" icon="money-bill" %}
若僅犯有輕度民事過失（CS1 或 CS2）：
- 駕駛飛船前往邊境非軍事哨站或特定空間站內部的 **行政罰款終端機 (Fines Terminal)**。
- 查詢名下罰單並以 aUEC 結清所有積欠罰金，通緝狀態將立即消除。
{% endtab %}

{% tab title="途徑二：克萊雪監獄勞動服刑 (穩健減刑)" icon="person-digging" %}
若不幸被捕入獄：
- **掛機自然等待**：刑期會依罪行嚴重程度在數十分鐘至數小時間倒數。
- **深層礦坑挖礦減刑**：領取多功能礦槍，深入監獄底層迷宮礦洞開採 Hadanite 等高價礦石，運回終端機兌換功績點數 (Merits)，可將數小時刑期大幅縮短至 15 分鐘！
- **氧氣維生挑戰**：越往深層礦坑推進，氧氣消耗越快，需及時尋找加氧站。
{% endtab %}

{% tab title="途徑三：潛入 SPK 駭入安全主機 (高危刺激)" icon="terminal" %}
對於不想坐牢的亡命之徒：
- **取得駭客晶片 (Cryptokey)**：在 GrimHEX 黑市購買 Tigerclaw 等駭入晶片。
- **潛入 Kareah 安全哨站 (SPK)**：位於 Crusader 星系上空的高戒備軍事哨站。
- **突破安保與主機解碼**：擊敗駐守的精銳安保 NPC，將晶片插入中央伺服器主機，消除個人的每一筆罪行記錄。過程中必須抵禦趕來鎮壓的玩家賞金獵人！
{% endtab %}
{% endtabs %}
