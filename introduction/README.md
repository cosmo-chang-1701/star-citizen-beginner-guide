# 第零章：歡迎來到《星際公民》！

在我們開始談論硬體配備、挑選船艦和接取合約之前，讓我們先花點時間聊聊最核心的問題：《星際公民》（Star Citizen）究竟是一款什麼樣的遊戲？

建立對這個項目的正確認識與心理預期，能讓你在接下來數百小時的星際旅程中獲得最佳樂趣，少踩許多老玩家曾走過的彎路。

---

## 🎯 本章核心目標

- **理解宏觀理念：** 體會「第一人稱宇宙 (First-Person Universe)」與傳統太空射擊遊戲的根本差異。
- **理清專案雙核心：** 搞懂多人持續宇宙 (PU) 與即將面世的單人戰役《42 中隊》(Squadron 42) 的分工。
- **建立健康心態：** 掌握身處 Alpha 測試階段必備的調適技巧與社群求助思維。
