# Alpha 4.10.0：圍攻奧里森 (Siege of Orison)

{% embed url="https://www.youtube.com/watch?v=Jn7yM2dg0rI" %}

公民，歡迎來到 Alpha 4.10。惡名昭彰的極端不法組織「九尾」(Nine Tails) 對十字軍星的奧里森 (Orison) 發動了殘暴襲擊，企圖徹底摧毀這座浮空之城的安全形象。十字軍保全 (Crusader Security) 緊急委託私人安保公司「北境之巖服務團隊」(Northrock Service Group) 組織突擊隊，號召公民們挺身而出奪回城市。

本次更新不僅帶來了全面重製為純 FPS 體驗的「圍攻奧里森」，更首次在線上宇宙 (PU) 實裝了劃時代的「副本化技術」(Instancing)，並引入了超重型護甲級別、雙模式實彈步槍與深度的製造兌換體系。本指南將協助你快速掌握新版本的核心變革與戰術重點。

## 1. 核心玩法：圍攻奧里森 (Siege of Orison)

九尾全面封鎖了奧里森空域，突擊小隊必須搭乘專用穿梭機 (Secure Shuttle) 滲透至三大浮動平台。三大平台場景均經過重新設計，具有更緊湊的戰鬥動線與開闊的交火視線。

| 戰鬥要素 | 機制特色 | 戰術建議 |
| :--- | :--- | :--- |
| **滲透與部署** | 空域遭防空網路封鎖，全員搭乘專用穿梭機進入。 | 進入前確認全員彈藥與醫療物資完備，由隊長開啟副本載入。 |
| **敵方階級體系** | 雜兵（混穿裝備與刺青）、精英隊長（面具頭盔）至 3 款重裝 Boss。 | 遭遇重裝 Boss 時集中火力攻擊弱點，善用掩體規避重機槍壓制。 |
| **無限醫療檢查點** | 副本內部署了無限次使用的醫療床檢查點。 | 陣亡將直接於副本內最近檢查點復活，不消耗醫療凝膠 (MedGel)，無需返回醫院。 |
| **結算與物資掠奪** | 通關發放大額 aUEC、裝備製造藍圖與專屬武器塗裝。 | 沿途務必搜刮專屬物資箱，高機率取得稀有配件與重型軍火。 |

## 2. 底層革命：副本化技術 (Instancing T0)

Alpha 4.10 是《星際公民》首度在 Persistent Universe 引入封閉式獨立副本空間：

*   **專屬空間隔離**：進入支援副本的區域（圍攻奧里森任務區、列夫斯基雷科辦公室）時，隊伍將進入專屬的鏡像空間，不受外部其他玩家干擾。
*   **副本調度代理 (Instancing Broker)**：負責副本的動態分配、人數上限控管、生命週期管理與閒置資源回收。
*   **伺服器負載彈性擴展 (Server Load Scaling)**：改以「總幀時間」(Total Frame Time) 動態計算伺服器負載，大幅降低伺服器過載與記憶體溢出 (OOM) 崩潰；背包與存儲查詢改為並行處理，解決物資數據不同步問題。
*   **長期持續性 (LTP) 擴展**：礦石吊艙 (Ore Pods) 與大宗商品貨櫃正式納入 LTP 系統，跨版本獲得數據保存。

## 3. 傳奇回歸：雷科·巴塔利亞與維克洛百貨

*   **雷科·巴塔利亞 (Recco Battaglia)**：曾因礦難截肢的前深空礦工，現於列夫斯基 (Levski) 親自發放任務。完成 3 個引導故事任務後，可解鎖碎石、礦工防衛、失蹤人口與物品回收等可重複合約，獎勵偏向採礦模組與礦石吊艙製造藍圖。
*   **維克洛百貨 (Wikelo Emporium)**：
    *   **飛船訂製兌換**：於展廳看板接取合約並獲得單次藍圖，在製造機製作專屬物品後經由貨運電梯交付。可選擇立即降下發射台換乘新船，或直接存入主機庫。
    *   **藍圖永久保留**：裝備兌換成功後將永久保留對應藍圖，可日後自行採集資源生產。

## 4. 單兵武裝：超重型護甲與雙模式步槍

*   **BUL-H4 裝甲套裝**：包含一體式超重型護甲、專用頭盔與 H4-PBF 彈藥背包。犧牲移動速度換取極致防禦力，為單兵承載頂級重火力的唯一選擇。
*   **啟示錄軍備「仇殺」重機槍 (Vendetta HMG)**：配合 BUL-H4 裝甲使用的毀滅性單兵連射機槍，背包可攜帶大量專用彈鏈箱，支援隊友使用牽引光束或手動快速填裝。
*   **赫德比槍械「阿靈頓」步槍 (HDGW Arlington Rifle)**：具備雙射擊模式的實彈槓桿長槍：
    *   **精確射手模式 (DMR)**：單發 70 傷害，初速 550 m/s，射程遠且精度極高。
    *   **霰彈模式 (Shotgun)**：單發 8 顆彈丸（每顆 12.5 傷害），初速 300 m/s，近戰具備毀滅性瞬間爆發。

| 武器/裝備類型 | 核心優勢 | 適用情境 |
| :--- | :--- | :--- |
| **BUL-H4 + 仇殺重機槍** | 極限減傷、持續性強大火力壓制。 | 攻堅防禦要塞、正面吸引敵方 Boss 火力。 |
| **阿靈頓步槍** | 遠近兼備，靈活切換 DMR 與霰彈模式。 | 中遠距離點殺與突入室內近戰清繳。 |

## 5. 戰鬥平衡：燃油、護甲與載具武器

*   **燃油系統再平衡**：全艦隊氫燃料箱容量與消耗率同步下調，維持相近有效續航，但大幅調漲氫燃料與量子燃料售價。
*   **護甲減傷機制修復**：徹底修復「護甲血量歸零仍提供 25% 固定減傷」的問題，破損護甲不再提供減免，傷害計算全面物理化。
*   **武器數值調整**：S4 實彈加特林傷害提升約 68%，具備破甲威懾；S4 聯合加農砲 (Combine Cannon) 移除過大濺射，轉為純直擊武器。

## 6. 新增載具與技術升級

*   **新增與更新載具**：
    *   **克魯格 S-65「刺魟」(Kruger S-65 Stingray)**：全新可變形中型戰鬥機。
    *   **克魯格 P-52「梅林」(Kruger P-52 Merlin)**：中軸主炮改為可動掛點 (Gimbal) 支援自由改裝。
    *   **商店解鎖**：克魯格 L-22「阿爾法狼式」、武藏 貨輪 B (MISC Hull B)、德雷克「魔像」OX、灰貓工業 UTV 於新交易中心與展廳開放購買；RSI「極光」Mk II 全面取代 Mk I。
*   **實驗性 VR 與音效沉浸技術**：
    *   **VR 系統大升級 (OpenXR 1.1.60)**：全域頭部追蹤、立體游標 (Stereo Cursor)、防止視角穿牆之幾何碰撞反饋、雙眼水體模擬與 G 力黑視效果同步。
    *   **動態音效**：圍攻奧里森專屬戰鬥原聲帶（環境、交火、Boss 戰、勝利音軌）、加油操作介面完整語音與音效反饋。

> **專家提示**：在 4.10.0 的圍攻奧里森中，建議小隊中至少配置一名穿戴 BUL-H4 裝甲與「仇殺」重機槍的重裝隊員作為前排火力壓制點，其他隊員攜帶牽引光束隨時協助更換 H4-PBF 背包彈鏈。善加利用無限醫療床檢查點，穩紮穩打推進平台！
