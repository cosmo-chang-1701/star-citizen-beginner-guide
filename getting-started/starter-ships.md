# 1.3：我的第一艘船該怎麼選？一個影響深遠的決定

你的第一艘飛船不僅是你在宇宙中的第一個「家」，更是你在星際中賺取第一桶金的核心生產力工具。

過去新玩家入坑時，往往需要在眾多新手遊戲包中猶豫不決。為了徹底解決選擇困難，CIG 官方商城已全面整合為單一官方標準包：**[Star Citizen First Flight Pack (星際公民首航包)](https://robertsspaceindustries.com/en/pledge/Packages/Star-Citizen-First-Flight-Pack)**。新玩家無需在第一天冒險購買高單價的專門船，只需以首航包起步，即可獲得永久主力入門艦以及官方贈送的 30 天多職業體驗艦隊！

## 官方統一首航包：RSI 極光 Mk II 與 30 天體驗艦隊

這是繼承了經典極光系列精神的新一代入門機型，也是羅伯茲太空工業 (RSI) 為所有新進公民打造的最穩健起跑線。

| 評估維度 | 詳細說明 |
| :--- | :--- |
| **官方購買** | [Star Citizen First Flight Pack 官方首航包](https://robertsspaceindustries.com/en/pledge/Packages/Star-Citizen-First-Flight-Pack) |
| **艦船定位** | **多功能通用輕型入門機** |
| **核心優勢** | **超高性價比、模組化空間**。Mk II 優化了內部空間結構，保留了可供隨時離線休息存檔的**生活床位**，並具備可掛載小型貨物的外部貨格與可靠的護盾系統。 |
| **適合玩法** | 基礎快遞貨運、初階維修調查、輕型巡邏任務。 |
| **老鳥評語** | 作為首航包的核心主力，極光 Mk II 具備麻雀雖小五臟俱全的特性。享有隨時在星空中離線躺平的權利，是性價比無可挑剔的起點。 |

### 30 天多職業體驗艦隊 (30-Day Loaners)

購買首航包後，官方將特別提供 30 天的三艘專門船艦租借權限 (Loaners)，讓你在不需要額外花費的前提下，親身體驗宇宙中的三大核心經濟支柱：

| 體驗艦船 | 製造商與定位 | 核心體驗內容 |
| :--- | :--- | :--- |
| **魔像 (Drake Golem)** | **德雷克星際**<br>輕型採礦專用機 | 整合輕型採礦雷射頭與物資粉碎裝置，親身體驗小行星帶與地表礦石勘探開採，賺取穩定的工業收入。 |
| **財運 (MISC Fortune)** | **武藏工業與星航公司**<br>輕型打撈專用機 | 搭載打撈光束與殘骸回收處理模組，體驗剝離艦船裝甲與回收高價值結構物資的打撈樂趣。 |
| **無畏 (Crusader Intrepid)** | **十字軍工業**<br>輕型穿梭貨運機 | 配備標準內部貨物網格與出色的亞光速航行性能，體驗在星系各大空間站與前哨站之間高效運送物資。 |

## 熱門進階目標與升級路徑 (CCU & aUEC)

在體驗了極光 Mk II 以及 30 天租借艦隊之後，如果你找到了自己熱衷的發展方向，或者希望獲得更強大的戰鬥與運輸能力，該如何升級？

你完全不需要重新購買新遊戲包，官方提供了兩種平滑升級途徑：

1. **官網升級系統 (Cross-Chassis Upgrade / CCU)：** 在官網 Pledge Store 的「Ship Upgrades」中，選取現有的極光 Mk II，只需**補齊差價**即可無痛升級成目標艦船，原有遊戲資格與保險完全保留！
2. **遊戲內購買 (aUEC)：** 在遊戲內各大主城艦船展廳（如新巴貝奇 Astro Armada、羅威爾 New Deal），直接使用任務賺取的遊戲貨幣 aUEC 購買，完全免費！

以下是新進公民最推薦的兩款進階目標艦船：

### 1. 全能進階王者：Aegis Avenger Titan (聖盾動力 復仇者 泰坦)

泰坦在當前宇宙環境中依然穩坐「新手全能霸主」的寶座，是戰鬥與多功能任務的首選升級目標。

| 評估維度 | 詳細說明 |
| :--- | :--- |
| **升級途徑** | [購買首航包](https://robertsspaceindustries.com/en/pledge/Packages/Star-Citizen-First-Flight-Pack) 後於官網透過 **Ship Upgrades (CCU)** 補差價升級，或於遊戲內以約 130 萬 aUEC 購買。 |
| **艦船定位** | **戰鬥 / 運輸雙修萬金油** |
| **核心優勢** | **全能性無可替代**。機鼻搭載 4 號武器掛點，具備強大的中程火力；擁有 8 SCU 的內部實體貨艙，尾部**平整坡道門**讓你在運送物資或地堡突擊搬運裝備時極其便捷。 |
| **適合玩法** | 中級賞金空戰、武裝護航、地堡戰術突擊、多階段複雜合約。 |
| **老鳥評語** | 若預算允許額外補差價升級，泰坦能讓你直接跳過新手前期的貧弱過渡期，具備參與宇宙中絕大多數高收益活動的能力。 |

---

### 2. 工業專精首選：Drake Golem (德雷克星際 魔像)

如果你在 30 天試用期內深深愛上了採礦的寧靜與致富感，魔像是最值得永久保留的專屬工業船。

| 評估維度 | 詳細說明 |
| :--- | :--- |
| **升級途徑** | [購買首航包](https://robertsspaceindustries.com/en/pledge/Packages/Star-Citizen-First-Flight-Pack) 後於官網透過 **Ship Upgrades (CCU)** 補差價升級，或於遊戲內使用 aUEC 購買。 |
| **艦船定位** | **工業採礦與物資處理專用機** |
| **核心優勢** | **自帶專業工具**。整合了輕型採礦雷射頭與物資粉碎裝置，讓玩家直接參與宇宙中最穩健的經濟循環：採礦與精煉。 |
| **適合玩法** | 小行星帶勘探、地表露天採礦、精煉廠加工貿易。 |
| **老鳥評語** | 厭倦打打殺殺的玩家的最佳福音！魔像的外型雖然粗獷，卻是新手致富速度最快、最不依賴戰鬥技巧的工業金鑰匙。 |

## 決策指南：新手起步最優解

- **步入宇宙第一步：** 毫不猶豫直接購入 **[Star Citizen First Flight Pack (官方首航包)](https://robertsspaceindustries.com/en/pledge/Packages/Star-Citizen-First-Flight-Pack)**，用最具性價比的支出開啟星際冒險。
- **30 天試用期善加探索：** 善用贈送的 **德雷克星際 魔像**、**武藏工業與星航公司 財運** 與 **十字軍工業 無畏**，摸索採礦、打撈與貨運的樂趣。
- **渴望強悍火力、重視機庫空間與實用性：** 30 天後或上手後，推薦將極光 Mk II 透過 CCU 升級為 **聖盾動力 復仇者 泰坦**。
- **立志成為全職採礦大師：** 透過 CCU 升級或遊戲內 aUEC 購買將 **德雷克星際 魔像** 轉為永久收藏。

{% hint style="info" %}
**官方飛船升級機制 (Cross-Chassis Upgrade / CCU)：**
在官網「Pledge Store」->「Ship Upgrades」中，選取左側為你的「Aurora Mk II」，右側選取你想升級的目標艦船（例如 Avenger Titan 或 Drake Golem），只需支付兩者之間的官方定價差額。升級套件購買後需至官網「My Hangar」中點選「Apply Upgrade」套用，原本首航包的遊戲資格 (Game Package) 與保險都會完整保留！

如果你未來打算規劃中大型艦隊，或追求最高達 30%~60% 的折價省錢黑魔法，請務必參閱進階專題：👉 **[附錄 E：CCU 跨底盤升級完全指南與最佳實踐](../appendix/ccu-guide.md)**。
