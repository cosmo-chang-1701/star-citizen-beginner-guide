# 1.4：打造你的數位化身！角色創造（BiotiCorp）全指南

在目前的宇宙中，角色創造系統（內部代碼為 **BiotiCorp**）已經過全面革新。這不再只是單純調整臉部數值，而是一個結合了基因工程混合與直覺式筆刷雕刻的強大系統。

---

## BiotiCorp 捏臉系統全流程

{% stepper %}
{% step %}
### 掌握「基因剪輯」與「直覺雕刻」

目前的系統核心是 **基因剪輯 (Gene-Splicing)** 與 **直覺雕刻 (Direct Sculpting)** 的無縫結合：

- **基因剪輯 (Gene-Splicing)：** 你不再是從零開始捏臉，而是從龐大的來源頭像庫（由真實人類高精度掃描而成）中挑選多個基礎基因。你可以挑選 A 的鼻子、B 的下巴、C 的額頭，並自由滑動調整混合權重。
- **直覺雕刻 (Sculpting Mode)：** 進入雕刻模式後，你可以直接在角色的臉部各區域（如眼睛、耳朵、顴骨等位置）點擊並拖曳，直覺微調臉部輪廓，打破預設基因的限制。
- **膚色與質感細節：** 除了基礎膚色，還能調整皮膚粗糙度、出油光澤感以及面部歲月風霜痕跡。
{% endstep %}

{% step %}
### 髮型、鬍鬚與毛髮動態調色

髮型系統採用了物理層級的模擬技術，視覺效果極為逼真：

- **多樣化髮型與體積毛髮：** 遊戲提供豐富的男女髮型庫與鬍鬚（Beards / Stubble）選項。新一代「體積毛髮」技術能確保戴上頭盔或帽子時自然收納收縮，避免產生穿模現象。
- **雙色漸層與黑色素控制：** 透過全彩 RGB 色環精準挑選主色，並能獨立調整**髮根與髮尾的漸層過渡**。透過「黑色素 (Melanin)」滑桿，還能呈現自然老化的挑染白髮質感。
{% endstep %}

{% step %}
### 身體藝術：刺青、穿孔與彩妝

角色外觀個性化進一步延伸至身體裝飾與化妝藝術：

- **刺青工藝 (Tattoos)：** 提供多樣風格的全身與面部刺青，支援色彩調整，並可透過「老化 (Age)」滑桿模擬刺青隨歲月風化褪色的真實效果。
- **金屬穿孔 (Piercings)：** 支援為角色佩戴各式耳環、鼻環與唇飾。
- **眼影與戰繪 (Makeup & Face Paint)：** 精確定義眼影、腮紅、唇彩飽和度以及部族風面部迷彩戰繪。
{% endstep %}

{% step %}
### 保存與分享 DNA 基因代碼

精心雕琢的角色樣貌絕不能輕易遺失：

- **匯出本機與代碼生成：** 在完成介面可將角色數據一鍵匯出為設定檔，或生成專屬的 **DNA 代碼字串**。在版本數據重置（Wipe）後能秒速還原心愛外觀。
- **社群外觀庫共享：** 你可前往 [Star Citizen Characters](https://www.star-citizen-characters.com/) 等社群庫下載其他公民分享的代碼，快速套用帥氣或擬真的角色造型。
{% endstep %}

## 異常排查與環境認知

### 解決角色創建循環與同步問題

在 Alpha 測試環境中，若遭遇完成設定後跳回起點的循環問題：

1. **刪除 USER 文件夾快取：** 完全關閉遊戲與啟動器，刪除安裝目錄 (`StarCitizen\LIVE\USER\`) 快取檔案，消除本機與伺服器資料衝突。
2. **切換登入地區伺服器：** 在主選單將 Region 從 BEST / ASIA 切換至 US / EU，強制觸發伺服器重新拉取帳號雲端角色狀態。
3. **官網 Character Repair：** 若依然無法同步，前往 RSI 官網帳號後台使用 Character Repair 工具，並靜置 1 小時後重新登入。

> [!TIP]
> 宇宙中的動態光影（如太空港霓虹、星球恆星強光）會顯著改變面部陰影與膚色表現。捏臉時請適度切換視角光線，以達到最平衡的視覺效果。
