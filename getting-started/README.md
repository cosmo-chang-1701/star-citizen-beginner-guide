# 第一章：出發前的準備，讓我們一步步來

好了，公民！既然你已經對《星際公民》有了基本的認識和心理準備，接下來就是動手操作的時刻了。

本章節將像一份詳細的操作清單，引導你完成進入宇宙前的所有準備工作，從確認你的電腦能否順暢勝任，到為你挑選最合適的第一艘新手船艦與出生主城。

---

## 🎯 本章核心目標

- **硬體與系統到位：** 避免因為 HDD 硬碟或 RAM 不足而產生嚴重的遊戲卡頓崩潰。
- **買對遊戲包：** 理解「遊戲包」與「單飛船」的根本區別，掌握推薦碼贈送初始 aUEC 的關鍵時機。
- **選對啟航船艦：** 評估性價比最佳的新手飛船（極光、泰坦或惡魔採礦船）。
- **選定起點家園：** 依據你的偏好玩法（貨運、工業或戰鬥）挑選最適宜的初始星系主城。
