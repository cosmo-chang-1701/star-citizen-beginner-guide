# 第二章：你的第一步，從睡夢中醒來到飛向宇宙

恭喜你！完成註冊並下載好遊戲後，最激動人心的時刻到了。

當你第一次載入進 Persistent Universe (PU)，你將身處陌生公寓或醫療中心的床上。本章節將帶你完整體驗遊戲初期的關鍵流程：從學會活動肢體、熟悉你的個人多功能手環 mobiGlas、搭乘城市地鐵穿梭前往太空港，直到最後坐在駕駛艙內，按下啟動按鈕進行人生第一次量子跳躍！

---

## 🎯 本章核心目標

- **熟悉基礎互動：** 熟練掌握 `F` 鍵凝視互動滾輪與個人物品欄管理。
- **玩轉超級手環：** 學會 mobiGlas 導航星圖、任務接取終端與飛船修復保養介面。
- **城市無障礙通勤：** 不再在龐大的摩天都市迷路，順利搭乘大眾運輸前往太空中心。
- **首次衝向深空：** 掌握垂直起飛、脫離大氣、機動鎖定與星際量子躍遷。
