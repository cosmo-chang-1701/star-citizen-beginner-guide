# 2.1：醒醒，公民！熟悉你的基本動作與互動

當你初次載入宇宙時，角色會在起點居住區的單人公寓床鋪上甦醒。面對高度擬真的物理宇宙，第一小時最重要的就是掌握身軀操作與核心互動系統。

---

## 徒步移動與核心互動系統

### 初次甦醒與基礎移動

- **離開床鋪**：按下 `Y` 鍵即可起身離開床鋪。
- **基本方向控制**：與典型第一人稱射擊遊戲相同，使用 `W`、`A`、`S`、`D` 控制走動，滑鼠移動控制視角。
- **奔跑與衝刺**：按住 `左 Shift` 鍵進行跑步加速。
- **跳躍與翻越**：按下 `空白鍵` 可進行跳躍，在遇到矮障礙時可自動翻越。

### 核心「按住 F 互動機制」(Inner Thought System)

這是《星際公民》最具代表性的操作哲學：

- **啟動互動**：將準星對準任何可互動實體（門開關、電梯按鈕、杯子、終端機），**長按 `F` 鍵**。
- **選擇指令**：維持按住 `F` 鍵不放，螢幕上會浮現「Open」、「Call Elevator」或「Inspect」等動態選項。
- **確認執行**：滑鼠滑動至該選項後，點擊 **`滑鼠左鍵`** 執行動作。
- **快速點擊**：對於最常見的單一動作（如開門），也可以直接**快速點擊一下 `F` 鍵**觸發預設操作。

---

## 裝備與背包庫存管理

### 個人物品欄 (`I` 鍵)

- **呼叫個人庫存**：隨時按下 `I` 鍵即可開啟全息背包介面。
- **左右分欄佈局**：
  - **左側**：目前所在位置的本地倉庫（Local Inventory）或外部容器。
  - **右側**：穿戴在角色身上的護甲、頭盔、武器、戰術背包及隨身口袋。

### 常用物品管理技巧

- **快速穿戴**：在倉庫物品上點擊 **`滑鼠左鍵雙擊`**，系統會自動將裝備穿戴到對應部位。
- **批量轉移**：按住 **`Shift + 滑鼠左鍵單擊`**，可將該物品瞬間在角色背包與本地倉庫之間秒速移轉，大幅節省拖曳時間。

## 第一小時核心快捷鍵速查

在遊戲的第一個小時中，你最常用到的關鍵按鍵如下：

| 按鍵 | 功能說明 | 實戰重要性 |
| :--- | :--- | :--- |
| `F` (長按 / 單擊) | 核心動態互動 / 執行預設操作 | ⭐⭐⭐⭐⭐（全宇宙最頻繁使用） |
| `I` | 開啟個人背包與裝備庫存 | ⭐⭐⭐⭐⭐（整理物資） |
| `F1` | 開啟 mobiGlas 個人數位腕錶腕帶 | ⭐⭐⭐⭐⭐（接任務、查錢包） |
| `F2` | 快速直達全息星圖 (Skyline Star Map) | ⭐⭐⭐⭐⭐（導航跳躍定位） |
| `左 Alt + H` | **穿戴 / 脫卸頭盔** | ⭐⭐⭐⭐⭐（在氣密艙外嚴禁脫下！） |
| `C` | 快速注射醫療針 (MedPen) | ⭐⭐⭐⭐（急救止血保命） |
| `4` | 裝備多功能工具 (牽引光束 / 醫療槍) | ⭐⭐⭐⭐（搬貨與精準急救） |
| `G` | 投擲手榴彈 | ⭐⭐⭐（戰鬥投擲） |

> [!WARNING]
> 出入太空港氣密門或前往無大氣星球前，請務必確認頭盔已正確佩戴（按 `F4` 切換第三人稱檢查），否則將在 10 秒內因窒息昏迷。
